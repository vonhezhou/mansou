# 文档入口

- `technical_design.md`：技术设计。
- `execution_plan.md`：阶段执行计划。
- `deployment.md`：NAS/VPS、Docker、HTTPS 反向代理和备份说明。
- `source_compatibility.md`：真实源兼容矩阵和验证流程。
- `api.md`：OpenAPI 地址、导出和客户端生成说明。
- `web_architecture.md`：`apps/web` 前端结构、API 访问约定、测试和后续迭代规则。

- `auth.md`：鉴权模式、管理员初始化、Session、API Token、密码重置和旧配置迁移。
